4px steps from `--gw-space-1` to `--gw-space-20`, plus a 2px half step, multiplied by the theme's density (0.85 compact, 1 normal, 1.2 roomy). `--gw-space-N` is N × 4px at normal density. Terminal UIs use cells instead. An app sets any step or `--gw-density` itself, as [Overriding tokens](/themes#overriding-tokens) shows.

Each bar below is the token itself, drawn in the theme, so it changes with density.

## Sizes

Controls share a set of heights, so they line up in a row. `--gw-button-scale` sets any other button size.

<TokenScale kind="size" />

| Control | Height |
| --- | --- |
| Button `xs`, `small`, `medium`, `large`, `xl` | 24, 32, 40, 48 and 56px |
| Input and select | 40px |
| Badge | 36px, 18px icon |
| Chip | 28px |
| Toggle (segmented control) | 40px track, 32px options |

Each component page measures its own parts the same way, in its anatomy.

## Touch targets

A finger is bigger and less exact than a mouse, and it hides what it presses. So every control has a hit area of at least `--gw-target-min`, the area a press lands on, even where it looks smaller.

| Pointer | `--gw-target-min` |
| --- | --- |
| A mouse, trackpad or pen | `1.5rem` (24px) |
| Wherever a finger can point, `(any-pointer: coarse)` | `2.75rem` (44px) |

- **The hit area grows, not the look.** Padding, or an empty `::before` reaching past the control's edges, takes the press, so a 32px option in a toggle still has a 44px hit area that reaches past its track.
- **One press lands on one control.** Hit areas never overlap a neighbor's. Where a row is too tight for that, the controls themselves grow on a touch screen, or the gap between them does. Keep at least `--gw-space-2` (8px) between controls with a visible edge and `--gw-space-6` (24px) around ones without, such as an icon on its own.
- **Denser for a mouse.** With no finger to point, controls can be as small as their looks, down to 24px.
- **Bigger where it counts.** A control pressed often, one near the screen's edge, and one whose result can't be undone go above the minimum.
- **Text links inside a sentence** keep the line's height.

An app that wants Material's 48px sets `--gw-target-min: 3rem` under `(any-pointer: coarse)`. An app's own small control reaches the token with a hit area of its own:

```css
.my-control {
  position: relative;
}

.my-control::before {
  position: absolute;
  inset: min(0px, calc((100% - var(--gw-target-min)) / 2));
  content: "";
}
```

## Focus

Focus rings sit outside a control, so neighbors keep at least `--gw-space-2` between them; inside a track, such as a toggle's, the ring is inset instead. The ring is a 2px outline in `--gw-color-focus`, offset by 2px: `--gw-focus-width` and `--gw-focus-offset`. Terminals use reverse video or a marker.
