## App bar

  </gw-app-bar>

A site or app header pinned to the top of the page: a brand in the `brand` slot, nav links in the default slot and icon buttons in `actions`. It runs the full width of the page with its content kept to `--gw-content-width`, and stays transparent until the page scrolls; then it gets a blurred surface and a bottom border, and sets `floating`.

For a page that opens with a hero, set `reveal-after` to a selector for it, such as `[data-hero]`. The bar then stays transparent and hides its brand until the hero scrolls out from under it, so the hero's large logo hands over to the bar's small one. A hidden brand takes no room: the nav starts at the edge, then slides over as the brand opens. `overlay` lays the bar over the top of the page instead of taking room, so the hero starts at the very top.

Below `menu-below`, 600px wide by default, the nav moves into a menu opened from a button, which closes on Esc, a click outside or picking a link. The bar sets `collapsed` while it does. The button leads, with the brand beside it. `menu-label` names that button. Raise `menu-below` when the nav and the actions need more room than a row has, so the actions stay in the bar while the nav folds away.

### With a hero

### Lining up with the page

The bar keeps its content to `--gw-content-width`, with at least `--gw-space-3` either side. `gw-page` uses the same box, so a page inside it lines up with the bar at every width. Set `--gw-content-width` to change the width for both:

```html
<style>
  :root {
    --gw-content-width: min(87.5rem, 100vw - 6rem);
  }
</style>
<gw-app-bar>…</gw-app-bar>
<gw-page>…</gw-page>
```

`gw-page` must span the page, as the bar does. For content outside it, give the element the same box: `width: min(100% - 2 * var(--gw-space-3), var(--gw-content-width))` with `margin-inline: auto`.

| Element | What it does |
| --- | --- |
| `gw-page` | Centers a page's content at `--gw-content-width`, or the narrow width with `narrow` |
| `gw-stack` | Stacks its children with the theme's gap |
| `gw-row` | Lines its children up and wraps them; `nowrap` stops that |
| `gw-grid` | Fills columns at least `--gw-grid-min` (18rem) wide |

`gap="s"` or `gap="l"` changes the gap of a stack, row or grid.
