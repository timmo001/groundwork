| Attribute | Values |
| --- | --- |
| `variant` | `brand` (default), `neutral`, `info`, `success`, `warning` or `danger` |
| `appearance` | `accent` (default), `filled`, `outlined` or `plain` |
| `size` | `xs`, `small`, `medium` (default), `large` or `xl`; or set `--gw-button-scale` |
| `type` | `button` (default), `submit` or `reset` |
| `href` | Renders a link that looks the same |
| `icon` | SVG path data for an icon before the text |
| `labels` | `show` (default), `hide` for the icon only, or `auto` to hide the text on narrow screens |
| `label` | An accessible name, when the text doesn't say enough |
| `disabled` | Disables it |
| `loading` | Shows a spinning ring in the icon's place and ignores clicks |

It renders a native `<button>`, or an `<a>` with `href`. Put an icon in the `icon` slot. Style the inner element with `::part(button)`.

### Links in the page

An `href` link lives in the button's shadow root, so it isn't in the page's HTML. When the link has to be there, such as for `rel="me"`, a `target`, crawlers or `aria-current="page"`, put a plain `<a>` inside instead. The button styles it, a click anywhere on the pill follows it, and `aria-current` on it gets a current style:

<Demo id="button-links">

  <gw-button appearance="outlined"><a href="https://github.com/timmo001" rel="me" target="_blank">GitHub</a></gw-button>
</Demo>

`icon` takes SVG path data for an icon before the trigger's label.

Set `items` to `[{ "value", "label", "description", "icon", "disabled" }]`, as JSON or as a property. They render inside the component, so a page's own button styles can't reach them.

Contextual actions, such as "Add", go in `actions`, in the same shape. They stay below the items as the list scrolls, rather than sitting at the end of it, so they're found straight away, and there can be several. With no items, the menu says so (`empty`) above them.

## Theme picker

<Demo id="theme-picker">
  <gw-theme-picker theme="base" themes='[{"value":"base","label":"Base"},{"value":"glazing","label":"Glazing"},{"value":"survey","label":"Survey"}]'></gw-theme-picker>
</Demo>

A palette button for the page's look, for an app bar's `actions` slot. It opens a popover with the mode (auto, light, dark or Darker), the theme, an Import button for a theme file (a Groundwork theme's `.json` or an Omarchy `colors.toml`) and Reset. With fewer than two themes, such as a site with one theme of its own, the theme select hides until someone imports one.

It only asks: it fires `mode`, `theme`, `import` (with the file's `text` and `name`) and `reset`, and the page applies them and sets `mode`, `theme` and `themes` back. Show an import's result, such as roles that miss their contrast target, in `status`. [`pageTheme`](/themes/#on-a-page) does the applying and keeping:

```ts
import { coreThemeChoices, customThemeId, pageTheme } from "@timmo001/groundwork-tokens/page";

const page = pageTheme({ key: "my-site:theme", themes: coreThemeChoices, defaultTheme: "base" });
const picker = document.querySelector("gw-theme-picker")!;

const render = () => {
  const { mode, theme, custom } = page.state();
  picker.mode = mode;
  picker.theme = theme;
  picker.themes = [
    ...coreThemeChoices.map(({ id, name }) => ({ value: id, label: name })),
    ...(custom === null ? [] : [{ value: customThemeId, label: custom }]),
  ];
};

page.subscribe(render);
render();
picker.addEventListener("mode", (event) => page.setMode(event.detail.mode));
picker.addEventListener("theme", (event) => page.setTheme(event.detail.id));
picker.addEventListener("reset", () => page.reset());
picker.addEventListener("import", async (event) => {
  const result = await page.importTheme(event.detail.text);
  picker.status = result.ok ? `Using ${result.name}` : result.error;
});
```

### Mode button and inline controls

`layout` sets how the picker shows. `cycle` is a single button showing the mode in use, which steps to the next mode on each press, with nothing popping up. It suits an app bar. `inline` lays the controls out in place, in one wrapping row with Reset and Import, for a footer or a settings page. The picker is the row's flex container, so set `justify-content` on it to align the row. `modes` picks which modes to offer and in what order, such as leaving Auto out:

<Demo id="theme-picker-layouts" layout="stack">
  <gw-theme-picker layout="cycle" modes="light dark darker" mode="dark" label="Mode"></gw-theme-picker>
  <gw-theme-picker layout="inline" modes="light dark darker" mode="dark"></gw-theme-picker>
</Demo>

A site can use both, with a mode button in its app bar and the full controls in its footer. Wire each one to the same `pageTheme`, and set every picker's `mode` when its state changes so they stay in step:

```html
<gw-app-bar>
  …
  <gw-theme-picker slot="actions" layout="cycle" modes="light dark darker" label="Mode"></gw-theme-picker>
</gw-app-bar>
…
<footer>
  <gw-theme-picker layout="inline" modes="light dark darker" style="justify-content: center"></gw-theme-picker>
</footer>
```

Cards that each show a small app in a theme's colors: a rail, a panel and the status tones. It's for a settings page, or the theme picker's popover with `gallery`. Picking one fires `theme` with its `id`, as the picker does, so it pairs with [`pageTheme`](/themes/#on-a-page) the same way.

Give themes a `group` to keep a family together, such as a theme's light and dark variants. A group with only one theme joins the others like it under Other, at the end. The previews draw in `mode` from the theme CSS already on the page, so a custom theme `pageTheme` imported shows too. Call `refresh()` after an import changes that CSS.

| Attribute | Values |
| --- | --- |
| `theme` | The chosen theme's id |
| `themes` | JSON: `[{ "value", "label", "group" }]`, or set the property |
| `mode` | `auto`, `light`, `dark` or `darker`: the mode the previews show |
| `label` | Names the group for assistive technology. Defaults to `Theme` |

It's a `<fieldset>` of native radio buttons, so arrow keys move the choice. Set `--gw-theme-gallery-min` for wider or narrower cards, and style the `card`, `preview`, `name` and `group` parts.
