Groundwork is the shared starting point for designing and building the things in my repositories: how they look, how they behave and how they're put together. Each project builds on it in its own way. Every app starts from the same base and picks its own theme, so the apps stay related without looking the same or looking generated.

It isn't a web kit. The same design reaches web apps and sites, desktop apps, terminal apps and CLI output, Omarchy panels, Home Assistant cards and agents. Themes and tokens are written as data, and each target gets its own generator.

## Packages

Published on npm at one shared version:

| Package | What it is |
| --- | --- |
| [`@timmo001/groundwork-tokens`](https://www.npmjs.com/package/@timmo001/groundwork-tokens) | The theme schema, the OKLCH solver and every theme as CSS and JSON |
| [`@timmo001/groundwork-ui`](https://www.npmjs.com/package/@timmo001/groundwork-ui) | Framework-free web components, styled by the `--gw-*` tokens |
| [`@timmo001/groundwork-tui`](https://www.npmjs.com/package/@timmo001/groundwork-tui) | Terminal components: OpenTUI renderables on the terminal tokens |
| [`@timmo001/groundwork-report`](https://www.npmjs.com/package/@timmo001/groundwork-report) | The [report page](/reports): one self-contained HTML file built from blocks, with every theme |
| [`@timmo001/docs-kit`](https://www.npmjs.com/package/@timmo001/docs-kit) | Shared branding, layout and config for docs sites, also on [JSR](https://jsr.io/@timmo001/docs-kit) |
