Groundwork is the shared starting point for designing and building the things in my repositories: how they look, how they behave and how they're put together. Each project builds on it in its own way. Every app starts from the same base and picks its own theme, so the apps stay related without looking the same or looking generated.

It isn't a web kit. The same design reaches web apps and sites, desktop apps, terminal apps and CLI output, Omarchy panels, Home Assistant cards and agents. Themes and tokens are written as data, and each target gets its own generator.
